# 📊 HR Analytics Dashboard

## 🎯 Project Overview

This project analyzes employee attrition and performance using SQL, Python, and Power BI.

## 🛠 Tools Used

* SQL (Data Analysis)
* Python (Pandas for Data Cleaning)
* Power BI (Dashboard & Visualization)
* Excel (Data Source)

## 📌 Key Insights

* High attrition observed in early tenure employees
* Overtime significantly impacts employee exit
* Low satisfaction strongly correlates with attrition

## 📊 Dashboard Pages

* Overview
* Attrition Analysis
* Compensation & Performance
* Employee Experience
* Advanced Analytics
